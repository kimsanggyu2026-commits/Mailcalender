# 🪟 윈도우 11에서 처음부터 끝까지 (초보자용)

컴퓨터를 잘 몰라도 순서대로만 따라 하면 됩니다. **위에서 아래로** 천천히 진행하세요.
중간에 막히면 어느 단계에서 멈췄는지만 알려주시면 됩니다.

---

## 0단계. 무엇을 하는 프로그램인가요?
- 내 Gmail을 읽어 **중요 메일을 골라 요약**하고, 메일 속 **약속 날짜를 일정으로 정리**해 줍니다.
- 결과를 **텔레그램**으로 보내고 **노션(Notion)** 에 쌓아둘 수 있습니다(선택).
- 외부 AI를 쓰지 않아 **요금이 들지 않습니다.**

---

## 1단계. 파이썬(Python) 설치  ⏱️ 5분

프로그램을 실행하려면 '파이썬'이라는 기반 프로그램이 필요합니다.

1. 웹브라우저(엣지/크롬)에서 **https://www.python.org/downloads/** 접속
2. 노란색 큰 버튼 **「Download Python 3.x.x」** 클릭 → 파일 다운로드
3. 다운로드한 파일을 **더블클릭**해서 설치 시작
4. ⚠️ **매우 중요**: 설치 첫 화면 맨 아래 **「Add python.exe to PATH」** 체크박스를 **꼭 체크** ✅
5. **「Install Now」** 클릭 → 끝나면 **「Close」**

> 이 체크를 빠뜨리면 나중에 명령이 안 먹습니다. 안 했다면 파이썬을 지우고 다시 설치하세요.

---

## 2단계. 프로그램 파일 내려받기  ⏱️ 3분

1. 브라우저에서 이 프로젝트 깃허브 페이지를 엽니다
   → **https://github.com/kimsanggyu2026-commits/Mailcalender**
2. 초록색 **「Code ▾」** 버튼 클릭 → **「Download ZIP」** 클릭
3. 다운로드된 **Mailcalender-main.zip** 파일을 찾습니다(보통 '다운로드' 폴더)
4. 그 파일에 **마우스 오른쪽 클릭 → 「압축 풀기」(또는 "전체 압축 풀기")**
5. 압축이 풀린 **Mailcalender-main** 폴더가 생깁니다. 찾기 쉽게 **바탕화면**으로 옮겨두세요.

---

## 3단계. 명령 입력 창 열기  ⏱️ 1분

'명령 프롬프트'라는 검은 창에 글자를 입력해 프로그램을 실행합니다.

1. 2단계에서 만든 **Mailcalender-main 폴더를 더블클릭해서 엽니다**
   (안에 `main.py`, `requirements.txt` 등이 보여야 합니다)
2. 폴더 맨 위 **주소 표시줄**(파일 경로가 적힌 칸)을 **마우스로 클릭**합니다
3. 글자를 모두 지우고 **`cmd`** 라고 입력한 뒤 **엔터**
4. 검은 창이 뜨면 성공입니다. 이 창에 아래 명령들을 **한 줄씩 복사 → 붙여넣기(마우스 오른쪽 클릭) → 엔터** 하면 됩니다.

---

## 4단계. 필요한 부품 설치  ⏱️ 3분

검은 창에 아래를 붙여넣고 엔터:

```
py -m pip install -r requirements.txt
```

여러 줄이 주르륵 지나가고 멈추면 완료입니다.
(혹시 `py`가 안 된다고 나오면 `python -m pip install -r requirements.txt` 로 시도)

## 5단계. Gmail 읽기 권한 받기  ⏱️ 10분 (가장 어려운 부분, 천천히)

구글에 "이 프로그램이 내 메일을 읽어도 됩니다"라고 허락해주는 과정입니다.

### 5-1. 구글 클라우드 프로젝트 만들기
1. **https://console.cloud.google.com/** 접속 → 본인 구글 계정 로그인
2. 화면 맨 위 왼쪽 **프로젝트 선택 ▾** 클릭 → **「새 프로젝트」** → 이름 아무거나(예: `mail`) → **만들기**
3. 만든 프로젝트가 선택돼 있는지 확인(맨 위에 표시됨)

### 5-2. Gmail API 켜기
1. 위쪽 검색창에 **`Gmail API`** 입력 → 검색결과 **「Gmail API」** 클릭
2. 파란 **「사용 설정(Enable)」** 버튼 클릭

### 5-3. 동의 화면 만들기
1. 왼쪽 메뉴(☰) → **「API 및 서비스」 → 「OAuth 동의 화면」**
2. User Type: **「외부(External)」** 선택 → 만들기
3. 앱 이름: 아무거나(예: `mail`), 사용자 지원 이메일/개발자 이메일: **본인 Gmail** → 저장하고 계속
4. '범위', '테스트 사용자' 단계는 그냥 **저장하고 계속**으로 넘어갑니다
5. **「테스트 사용자」** 단계에서 **「+ ADD USERS」** → **본인 Gmail 주소 입력** → 저장 (이거 꼭!)

### 5-4. 자격증명(열쇠 파일) 만들기
1. 왼쪽 메뉴 → **「API 및 서비스」 → 「사용자 인증 정보(Credentials)」**
2. 위쪽 **「+ 사용자 인증 정보 만들기」 → 「OAuth 클라이언트 ID」**
3. 애플리케이션 유형: **「데스크톱 앱(Desktop app)」** 선택 → **만들기**
4. 팝업에서 **「JSON 다운로드」** 클릭 → 파일이 받아집니다
5. 받은 파일의 **이름을 정확히 `credentials.json` 으로 바꾼 뒤**,
   2단계의 **Mailcalender-main 폴더 안에 넣습니다** (main.py 와 같은 위치)

> 파일 이름이 `client_secret_xxx.json` 처럼 길게 받아지면, 이름을 `credentials.json` 으로 바꿔주세요.
> (윈도우에서 확장자가 안 보이면, 폴더 상단 「보기 → 파일 확장명」 체크)

## 6단계. 최초 로그인 (1회만)  ⏱️ 2분

검은 창(3단계 그 창)에 붙여넣고 엔터:

```
py scripts\get_token.py
```

- 잠시 후 **브라우저가 자동으로 열립니다** → 본인 구글 계정 선택 → 로그인
- "Google에서 확인하지 않은 앱" 경고가 나오면: **「고급」 → 「(앱 이름)(으)로 이동」 → 「허용」**
- 다 되면 검은 창에 `✅ token.json 생성 완료` 가 보입니다. 폴더에 `token.json` 파일이 생깁니다.

> 이 과정은 **처음 한 번만** 하면 됩니다.

## 7단계. 실행하기  ⏱️ 1분

검은 창에 붙여넣고 엔터:

```
py main.py
```

끝나면 폴더 안 **`output`** 폴더에:
- **`report.md`** — 메일 요약 보고서 (메모장으로 열어보면 됩니다)
- **`events.ics`** — 일정 파일 (더블클릭하면 캘린더에 넣을 수 있음)

🎉 여기까지가 **기본 사용**입니다! 텔레그램·노션·자동실행은 아래 선택 단계예요.

## (선택) 8단계. 텔레그램으로 결과 받기  ⏱️ 5분

1. 휴대폰 텔레그램에서 **@BotFather** 검색 → 대화 시작 → **`/newbot`** 입력 → 봇 이름 정하기
2. 받은 **토큰**(긴 문자열) 복사
3. 그 봇과 대화창에서 아무 메시지나 한 번 보냄
4. 브라우저에서 `https://api.telegram.org/bot복사한토큰/getUpdates` 접속
   → 화면에 나오는 `"chat":{"id": 숫자` 의 **숫자**가 chat id
5. Mailcalender-main 폴더의 **`.env.example`** 파일을 복사해 이름을 **`.env`** 로 바꾸고, 메모장으로 열어:
   ```
   TELEGRAM_BOT_TOKEN=복사한토큰
   TELEGRAM_CHAT_ID=복사한숫자
   ```
   처럼 채워 넣고 저장
6. 검은 창에서 확인: `py scripts\selftest.py --send`
   → 텔레그램에 테스트 메시지가 오면 성공

## (선택) 9단계. 노션에 쌓기  ⏱️ 7분

1. **https://www.notion.so/my-integrations** → **New integration** 만들고 **시크릿** 복사
2. 노션에서 결과를 모을 **데이터베이스(표)** 를 하나 만든 뒤, 우측 상단 **`···` → Connections → 만든 통합 연결**
3. 그 데이터베이스 주소(URL)에서 **물음표(?) 앞 32자리**가 DATABASE_ID
4. `.env` 파일에 추가:
   ```
   NOTION_TOKEN=복사한시크릿
   NOTION_DATABASE_ID=복사한32자리
   ```
5. 확인: `py scripts\selftest.py`

## ❓ 자주 막히는 곳
- **`py`가 인식되지 않습니다** → 1단계에서 "Add python.exe to PATH"를 안 한 것. 파이썬 재설치.
- **`credentials.json 가 없습니다`** → 5단계 파일을 폴더에 못 넣었거나 이름이 다름. 이름을 정확히 `credentials.json` 으로.
