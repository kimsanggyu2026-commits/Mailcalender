# ☁️ PC 없이 매일 무료 자동 실행 (초보자용)

목표: **내 PC가 꺼져 있어도, 매일 정해진 시각에 GitHub가 알아서 메일을 정리해 텔레그램/노션으로 보내기.**
비용: **무료** (GitHub Actions 무료 범위 + 외부 AI 미사용).

전체는 두 부분입니다.
- **A. 내 PC에서 딱 1번** — Gmail 로그인 토큰 만들기 (브라우저 로그인이라 최초 1회만 필요)
- **B. GitHub에서 설정** — 그 뒤로는 클라우드가 매일 자동 실행

---

## A. 내 PC에서 1회 — 토큰 만들기

> 이 부분은 `docs/시작하기-윈도우11.md` 의 **1~6단계** 와 동일합니다.
> 이미 하셨다면 폴더에 `token.json` 이 있을 거예요 → 바로 B로 가세요.

요약:
1. 파이썬 설치 (설치 시 **Add python.exe to PATH** 체크)
2. 이 프로젝트 ZIP 내려받아 압축 풀기
3. 폴더 주소칸에 `cmd` 입력해 검은 창 열기
4. `py -m pip install -r requirements.txt`
5. 구글에서 **credentials.json** 받아 폴더에 넣기 (윈도우 가이드 5단계)
6. `py scripts\get_token.py` → 브라우저 로그인 → **token.json** 생성 ✅

**여기서 만든 `token.json` 파일의 '내용'을 곧 GitHub에 넣습니다.**
→ 메모장으로 `token.json` 을 열어 **전체 내용을 복사(Ctrl+A → Ctrl+C)** 해두세요.

## B. GitHub에서 설정

### B-1. (중요) PR을 main에 합치기
> ⚠️ GitHub의 '매일 자동 실행'은 **기본 브랜치(main)에 있는 설정만** 작동합니다.
> 지금 코드는 작업 브랜치에 있으니, **main으로 합쳐야** 자동 실행이 켜집니다.

1. 저장소 페이지 상단 **「Pull requests」** 탭 클릭
2. 목록에서 우리 PR(제목: *Gmail 자동 분류…*) 클릭
3. 초록 **「Merge pull request」 → 「Confirm merge」** 클릭
   (원하시면 제가 대신 합쳐 드릴 수 있어요 — 말씀만 하세요.)

### B-2. 비밀값(Secrets) 등록
자동 실행이 Gmail에 접근하려면 아까 만든 토큰을 안전하게 넣어야 합니다.

1. 저장소 상단 **「Settings」** 클릭
2. 왼쪽 메뉴 **「Secrets and variables」 → 「Actions」**
3. 초록 **「New repository secret」** 클릭
4. 아래 값을 하나씩 등록:

| Name(이름) | Secret(값) |
|--|--|
| `GMAIL_TOKEN` | A단계에서 복사한 **token.json 전체 내용** |
| `TELEGRAM_BOT_TOKEN` | (선택) 텔레그램 봇 토큰 |
| `TELEGRAM_CHAT_ID` | (선택) 텔레그램 채팅 ID |
| `NOTION_TOKEN` | (선택) 노션 통합 시크릿 |
| `NOTION_DATABASE_ID` | (선택) 노션 DB ID |

> 이름은 **정확히 대문자로** 위와 똑같이 입력해야 합니다.
> 텔레그램/노션은 원하는 것만 넣으세요. 안 넣으면 그 알림만 건너뜁니다.

### B-3. Actions 켜기 & 첫 실행 테스트
1. 저장소 상단 **「Actions」** 탭 클릭
2. 처음이면 **「I understand my workflows, enable them」** 같은 버튼이 보이면 클릭해 활성화
3. 왼쪽에서 **「Mail triage (rule-based)」** 워크플로 선택
4. 오른쪽 **「Run workflow ▾」 → 「Run workflow」** 클릭 → 지금 즉시 1회 실행해봅니다
5. 잠시 뒤 실행 항목이 **초록 ✅** 이면 성공. 텔레그램/노션에 결과가 옵니다.
   (실패 ❌ 면 클릭해서 빨간 로그를 저에게 보여주세요 — 바로 잡아드립니다.)

## 완료! 이후로는?
- 기본값은 **매일 한국시간 오전 8시** 자동 실행입니다.
- 시각을 바꾸려면 `.github/workflows/triage.yml` 의 `cron: "0 23 * * *"` 를 수정
  (UTC 기준. 23시 UTC = 한국 08시. 예: 22 → 한국 07시)
- 결과는 저장소 `output/report.md` 에도 자동으로 쌓이고, 텔레그램/노션으로도 옵니다.

## 참고
- GitHub Actions는 **공개/비공개 저장소 모두 무료 범위**로 충분합니다(이 작업은 몇 분이면 끝남).
- 저장소에 60일 이상 아무 변화가 없으면 자동 스케줄이 잠시 멈출 수 있어요(가끔 커밋/수동 실행하면 유지).
- 민감 파일(`token.json`, `credentials.json`)은 **저장소에 올리지 마세요.** 반드시 **Secrets** 로만.
